# React + TypeScript

Projeto desenvolvido utilizando React, TypeScript e Vite, com o objetivo de praticar a criação de componentes, organização de código e navegação entre páginas.

## Criação do projeto

Comando utilizado para criar o projeto com o template React + TypeScript:

```bash
npm create vite@latest nome-do-projeto -- --template react-ts --legacy-peer-deps
```

## Instalação e configuração

**Instalação das dependências iniciais:**

```bash
npm install --legacy-peer-deps
```

**Instalação de uma versão específica do TypeScript:**

```bash
npm install -D typescript@6.0.3
```

**Instalação do React Router DOM:**

```bash
npm install react-router-dom
```

Utilizado para gerenciar a navegação entre diferentes páginas da aplicação.

## Executando o projeto

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

## Tecnologias utilizadas

- React 19
- TypeScript 6
- Vite 8
- React Router DOM 7
- ESLint 10
